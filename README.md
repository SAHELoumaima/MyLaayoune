# MyLaayoune — Discover the City

MyLaayoune is a web application designed to help residents and visitors discover useful places, services, and points of interest in Laayoune.

## Features

- Browse places and local services.
- View information about places and points of interest.
- Manage content through an administrative workflow.
- Responsive user interface.
- Multilingual interface support.

## Tech Stack

### Frontend
- React.js
- Redux Toolkit
- TanStack Query
- Tailwind CSS
- DaisyUI
- i18next

### Backend
- Node.js
- Express.js
- MongoDB
- Nodemailer

## Project Structure

- `frontend/` — User interface
- `backend/` — Server and API


## Getting Started

1. Clone or download the repository.
2. Install the dependencies in the frontend and backend folders.
3. Configure the required environment variables using a local `.env` file.
4. Start the backend server.
5. Start the frontend development server.

See the project configuration files for the exact installation and startup commands.

## Environment Variables

Create your own `.env` file for the required configuration. Never publish passwords, API keys, or private credentials.
